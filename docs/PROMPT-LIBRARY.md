# Prompt library sources and scope

Checked against official sources on 2026-11-01. The library contains 95 editorial
summaries across 16 providers. It includes all seven Common App topic choices,
all eight UC first-year PIQ choices, and the listed general first-year writing
questions from the other providers below. It does not claim most US institutions,
all specialized-program questions, transfer writing or all application platforms.

Each item links to its full official wording. Summaries are not verbatim questions.
Choice groups, platform and program restrictions are kept in the UI and copied to
editable notes. A missing cycle stays "Cycle not stated". Stanford's July 2026
update is recorded in its rules without inventing a cycle label. UC's question page
does not state a cycle. These records do not auto-refresh: confirm in the actual
application, especially after the listed cycle. Users may add any custom prompt.

Yale's short takes use 200 characters, separately from its word-limited essays.
MIT's page gives approximate ranges without exact question-level maxima; those
limits remain blank. Northwestern's "fewer than 200" becomes 199 in the planner.
Common App's 650-word maximum is also corroborated by Michigan's official essay
instructions: https://admissions.umich.edu/apply/first-year-applicants/essay-questions

The editor preserves source URL, cycle, checked date and summary/user-edited state
with each essay. It never overwrites a saved draft from the library; picking an
existing provider/prompt ID for a college reopens that essay. Prompt selection is
not a Save action. The library is local static content; no API receives writing.
