## What changed

The parser retains table headers and row/column labels, pairs timeline dates with application labels, and keeps parent round headings for nested cards. It excludes aid, notification, commitment, reply, testing, grade-report, interview, optional-arts, supplemental-material and gap-year dates from general application autofill. Ambiguous table spans or date ranges remain unresolved. Genuine differing application dates stay unfilled and expose their source excerpts.

Caltech’s QuestBridge proof-of-certification date is now isolated. Dartmouth’s QuestBridge-only process card is separated too. Production code contains no school-specific deadline values.

## Williams investigation

The main Williams source, bare williams.edu host, legacy admission.williams.edu host, catalog.williams.edu and hub.williams.edu returned access blocks in the tests. No challenge or crawler-rule check was bypassed. The [Common App Williams profile](https://www.commonapp.org/explore/williams-college/) found during investigation describes an older application cycle, so it was not adopted for current deadline autofill. Williams still needs the Paste page text method or manual review.

Amherst’s automatic Quick Pass and QuestBridge sources still load, but neither establishes its general application deadline. Its main checklist remains blocked.
